# awhp-launch changelog

What this is: one entry per commit in the `awhp-launch` repo; git holds the what, this holds the why.

## 2026-09-23 — Initial repo: README and CC BY-SA 4.0 license (`e9107b6`)

The open reference content for launching transactive air-to-water heat
pumps gets its own public repo, named after this wiki domain. Prose and
diagrams are CC BY-SA 4.0 on purpose: the model site, Heat Geek, keeps its
content proprietary to feed a training and installer business, and this
material is open so installers, utilities and manufacturers can adopt it
without lock-in, with the value sitting in dispatch and the operating
service.
