# Cross-cutting explorations (primary)

Status: Draft · Pass 0 · Updated 2026-06-07

> What this is: the hub for **cross-cutting explorations** — open design
> questions that don't belong to a single domain. The wiki-root counterpart to
> per-domain `wiki/<domain>/research/explorations/`, the same way `wiki/designs/`
> is the cross-cutting counterpart to per-domain `designs/`.

## What an exploration is

An *exploration* is an open question still being figured out — a curiosity /
uncertainty surface, not a worry (this is the renamed `concern`; see
[`glossary.md`](../glossary.md) "Where content lives"). It is not a ratified
plan (that's a `design`), not a settled pattern (that's `executor/`), and not
workflow state (that's Linear). When clarity emerges, an exploration graduates
into a design via `/grill-me`.

Cross-cutting explorations live here because they span repos/domains. Per-domain
ones stay under that domain's `research/explorations/`.
